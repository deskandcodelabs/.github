# Desk & Code Labs

Quant strategies, financial engineering and the AI systems that run them, in crypto, FX and beyond. By [Karim Soliman](https://www.linkedin.com/in/kaysoliman).

This is the open-source home of the [Desk & Code Labs](https://desklabs.substack.com) publication. Each tool or notebook here accompanies an essay, so readers can run the method themselves.

**What you will find here**
- **Fills & Edges:** execution research. Fill rates, queue position, maker and taker trade-offs, capacity.
- **From the Lab:** research method. Validation, simulator bias, honest measurement.
- **Structures:** trading structures and risk. Sizing, drawdowns, reconciliation and controls.

**Ground rules**
- Synthetic or public data only.
- No proprietary code, signals, parameters or live trading data. The work draws on research at Benchmark Trading Labs, the author's private lab, but nothing from that lab's codebase is published here.
